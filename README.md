# Tiny Stack VM

A tiny stack VM for make.fun's "Build a tiny stack virtual machine, 22 November 2026" bounty. It runs every program of a set on its input and writes the bytes it wrote plus its exit code.

[![rank](https://make.fun/badge/tiny-stack-vm-01-run-20261122/Xuzhiwei/tiny-stack-vm/rank.svg)](https://make.fun/bounty/tiny-stack-vm-01-run-20261122)
[![reward](https://make.fun/badge/tiny-stack-vm-01-run-20261122/Xuzhiwei/tiny-stack-vm/reward.svg)](https://make.fun/bounty/tiny-stack-vm-01-run-20261122)

Run: `node main.ts` with `MAKEFUN_INPUT_DIR` and `MAKEFUN_OUTPUT_DIR` set.
